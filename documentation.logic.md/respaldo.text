Configura mysqli para que lance excepciones (mysqli_sql_exception)
en vez de simplemente devolver false o warnings silenciosos ante un error.
Esta línea es la que habilita que el try/catch de abajo funcione — sin ella, un error de conexión no lanzaría excepción y el catch nunca se ejecutaría.

try {
    $conn = new mysqli($host, $user, $password, $db, $port);
} catch (mysqli_sql_exception $e) {
    die('Error de Conexion: ' . $e->getMessage());
}
Intenta crear la conexión con los 5 parámetros definidos arriba. Si falla (credenciales incorrectas
servidor caído, BD inexistente, etc.), captura la excepción y detiene la ejecución (die()) mostrando el mensaje de error.

$conn es la variable que todos los modelos (como Usuario.php) deben usar para hacer consultas ($conn->prepare(...), $conn->query(...), etc.).
Si cambia el nombre de la variable $conn, hay que actualizarla en todos los modelos que dependan de esta conexión

// usuario.php:

require_once __DIR__ . '/../config/database.php';
Carga el archivo de conexión a la BD (donde se crea $conn).
aquí la ruta apunta a database.php

private $conn;

public function __construct() {
    global $conn;
    $this->conn = $conn;
}

public function emailExiste(string $email): bool {
    $stmt = $this->conn->prepare(
        "SELECT id_usuario FROM usuarios WHERE email = ? LIMIT 1"
    );
    $stmt->bind_param('s', $email);
    $stmt->execute();
    $stmt->store_result();
    $existe = $stmt->num_rows > 0;
    $stmt->close();
    return $existe;
}
Devuelve true/false según si encontró filas. Usado en el controlador de registro para evitar emails duplicados.

public function buscarPorEmail(string $email): ?array {
    $stmt = $this->conn->prepare(
        "SELECT u.id_usuario, u.nombre, u.email, u.password, u.estado, u.id_rol, r.nombre AS rol
        FROM usuarios u
        INNER JOIN roles r ON u.id_rol = r.id_rol
        WHERE u.email = ?
        LIMIT 1"
    );
    $stmt->bind_param('s', $email);
    $stmt->execute();
    $result = $stmt->get_result();
    $usuario = $result->fetch_assoc();
    $stmt->close();
    return $usuario ?: null;
}
Este método es el que usará el login (authControllers.php) para traer los datos del usuario por email, incluyendo el password hasheado (para comparar con password_verify())
el nombre del rol vía JOIN con la tabla roles.
